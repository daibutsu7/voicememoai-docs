01
OVERVIEW

最初に知っておく3つの役割

「端末間の同期」と「クラウドへの書き出し」は別の機能です。

録音

iPhoneは対面向け

本体マイクで会話や講義を録音。ホーム右下の録音ボタンから始めます。

会議

Macはオンライン向け

マイクだけ、または画面の中の相手の声を含む会議録音を選べます。

活用

ノートは外へ書き出せる

Markdown、Frontmatter、フォルダ構造を設定し、Obsidianなどで利用できます。

02
IPHONE

iPhoneで対面の会話を録音する

録音、保存、文字起こし、ノート作成の順に進みます。

ホーム右下の録音ボタンを押す初回はマイク利用の許可を求められます。
必要なら録音条件を調整マイク感度、Bluetoothマイク、録音品質を選べます。Bluetooth接続中も本体マイク推奨です。
会話が終わったら「保存」一時停止・再開も可能。「保存しない」は確認後に破棄します。
録音を開き、ノートを作成文字起こし後、「ノート作成」で選択中のテンプレートに沿ったAIノートを生成します。
おすすめ

タイトルの手がかりを残す

録音画面のメモやカレンダー連携を使うと、あとで見つけやすくなります。予定が重なった場合は、保存後に紐付けるか確認され、予定名をタイトルにできます。

安心録音・文字起こしの保存は端末内で完結。AIノート生成時の外部AIへの送信は、内容を確認して同意した場合だけ行われます。
03
MAC

Macでオンライン会議を録音する

ツールバー、メニューバー、ショートカットの3経路から開始できます。

録音方法を選ぶ🎙 マイク録音 / 💻 会議録音（画面の中の音声も録音）
会議録音の同意を確認初回のみ、参加者への同意確認を促すリマインダーが表示されます。
終了時は「停止して保存」上部バーで保存・一時停止・破棄を明示的に選びます。
開始方法操作向いている場面
ウィンドウ録音ボタンで既定モード、横の ▾ で2択アプリを開いて作業中
メニューバーマイク録音 / 会議録音を選択ウィンドウを閉じているとき
キーボード⌥⌘Rすぐに既定モードで開始
会議アプリ検知Zoom / Teams / Webexの通知から録音忘れ防止
ブラウザ会議Google Meetなどは自動検知されません。ツールバー、メニューバー、または⌥⌘Rから手動で開始してください。
04
SCREENSHOT

録音中の画面をノートに残す

ワンタップで撮った画面や写真が、その瞬間の録音時刻に紐付きます。

Mac

共有スライドを撮る

Zoom・Teamsに映った資料を、録音を止めずに静止画で残せます。

iPhone

ホワイトボードを撮る

対面の会議では、板書や配布資料をカメラで撮って同じノートにまとめます。

ノート

時刻でつながる

サムネイルの時刻バッジから、その画面を撮った瞬間の音声へ移動できます。

【Mac】会議の前に画面キャプチャを準備する設定 → 一般 → 画面キャプチャ から許可し、アプリを再起動します。会議中には間に合わないため、事前に済ませてください。
録音中に📷を押すメニューバーの「📷 スクショを撮る」、録音中バーの📷ボタン、⌥⌘S のいずれかで撮影します。
初回だけ撮る対象を選ぶウィンドウまたは画面を選ぶピッカーが出ます。2枚目以降はワンタップで即座に撮影します。
対象を変えたいときは選び直す📷の横の ▾ から「対象を選び直す」、または ⌥⌘P で選択ピッカーを開き直せます。
事前準備

会議前に済ませる許可

Mac版の画面キャプチャには、macOSの「画面収録」の許可が必要です。許可の追加後はアプリの再起動も必要なため、会議中の操作では間に合いません。

設定 → 一般 → 画面キャプチャ で「準備する」から「再起動して有効化」まで進めておきます。Pro／Pro＋Macの購入直後と初回起動時の案内からも同じ準備ができます。

安心準備前に📷を押しても、短い案内が出るだけです。会議中にシステム設定へ飛ばされることはありません。
撮り方場所動き
📷 スクショを撮るメニューバーの録音中メニューアプリを前面に出さずに撮影
📷ボタン録音中バー横の ▾ から対象を選び直せる
⌥⌘Sキーボード（他のアプリが前面でも可）撮れるとメニューバーのアイコンが一瞬✓に変わる
⌥⌘S（録音していないとき）キーボード会議録音を開始し、そのまま1枚目の対象選択へ
⌥⌘Pキーボード（録音中のみ）選択ピッカーを開き直して対象を変更
【iPhone】録音中に「スクショを追加」を押す録音画面のボタンから、その場で画像を追加します。
「カメラで撮影」か「写真から選択」を選ぶホワイトボードや配布資料はカメラ、すでに撮ってある画像は写真ライブラリから取り込みます。
紐付く時刻はボタンを押した瞬間撮影や選択に時間がかかっても、話題になった瞬間の時刻で保存されます。
ノート

ノートでの見え方

ノート画面の「キャプチャ」に、時刻順のサムネイルが並びます。トピックの時刻に含まれる画像は、その見出しの近くにも表示されます。

  • 時刻バッジ ▶ mm:ss をタップして音声をシーク
  • サムネイルをタップで拡大、拡大表示から削除も可能
  • Mac：クリックすると左に大きく表示し、右のノートと見比べられる
  • Mac：境界をドラッグして画像とノートの幅を調整（比率を記憶）
  • ピンチで拡大縮小、ダブルクリックで等倍とフィットを切り替え
書き出し

Markdownにも画像が入る

iCloud Drive・Google Driveへの書き出しでは、画像も一緒に保存されます。トピックの中には小さめのサムネイルが横並びで入り、ノートの末尾には時刻リンク付きの原寸ギャラリーが付きます。Obsidianなどでそのまま表示できます。

05
LIBRARY

録音を整理し、ノートを育てる

Macは一覧性に優れ、iPhoneは移動中の確認と編集に便利です。

できること

タイトル編集、Markdown編集とプレビュー、フォルダ整理、横断検索、再生、データ別削除に対応します。

  • Finderから音声をドラッグして取り込み
  • 時刻リンクから再生位置へ移動
  • A− / A＋でノート文字サイズ変更
  • 録音やフォルダをドラッグで移動

フォルダ整理

案件・顧客・授業など、あとから探す単位で作ります。Macではドラッグ＆ドロップで移動でき、ホームへ戻すと未分類に戻せます。iPhoneでは「選択」から複数件をまとめて移動・削除・ノート作成できます。

06
ICLOUD SYNC

iPhoneとMacのライブラリをそろえる

両方の端末で「iCloudライブラリ同期」をONにします。

設定場所

iPhone：設定 → iCloudライブラリ同期
Mac：設定 → 同期

同じApple IDの端末で、録音一覧・フォルダ・ノート・文字起こしが自動的にそろいます。

同じApple IDか確認システム設定のApple Accountで確認します。
両方で同期をON初回は既存ライブラリのアップロードに時間がかかることがあります。
「音声も同期する」を選ぶOFFなら一覧・ノート・文字起こしのみです。
重要初回はWi‑Fi推奨。音声本体はあなたのiCloud容量に計上されます。
iCloudライブラリ同期ノート連携（書き出し）
目的iPhoneとMacを同じ状態にする成果物を汎用フォルダへ保存
対象一覧・フォルダ・ノート・文字起こし・任意で音声Markdown / テキスト・任意で音声
方向端末間の同期アプリからクラウドへの一方向
用途端末移行、紛失対策、端末連携Obsidian、外部保管、共有

09
TROUBLESHOOTING

困ったとき

よく起きる迷いどころを確認できます。

iPhoneの録音がMacに見えません

同じApple IDか、両方の「iCloudライブラリ同期」がONか確認。初回はWi‑Fiにつなぎ、しばらく待ちます。

ノートは見えるのに音声を再生できません

「音声も同期する」がOFFなら音声は共有されません。ONにし、iCloudの空き容量も確認します。

Google Meetを開いても通知が出ません

ブラウザ会議は自動検知されません。メニューバー、ツールバー、⌥⌘Rから開始します。

Macで相手の声が録音されません

「会議録音」を選び、システムオーディオ録音の許可を確認してください。この機能はPro＋Mac対象です。

Obsidianにファイルが出ません

Markdown、保存先Vault、「ノート」がONかを確認。自動連携OFFなら詳細の「ノート連携」で手動保存します。

AIノートを作成できません

データ送信への同意、利用可能時間、通信状態を確認。録音・文字起こし保存は別に端末内で行われます。

スクリーンショットが黒く写ります

Netflixなどの動画配信サービスは、著作権保護（DRM）によりOSがキャプチャをブロックするため黒く写ります。アプリの不具合ではありません。会議画面・ブラウザ・スライドは通常どおり写ります。

（Mac）画面キャプチャの事前準備とは

会議中に慌てないよう、設定 → 一般 → 画面キャプチャから、許可とアプリの再起動を事前に済ませておく機能です。準備が済んでいれば、録音中に⌥⌘Sを押すだけで画面を撮影できます。

Obsidianで時刻リンクを押すと警告が出ます

「This link will open an external application…」はObsidianの標準の確認メッセージです。「Always open voicememoai:// links」にチェックを入れると、以後は表示されなくなります。

書き出したノートの画像をクリックで拡大したい

画像の拡大表示はMarkdownビューア側の機能です。Obsidianでは「Image Toolkit」などのコミュニティプラグインを追加すると、クリックで拡大表示できます。

他の端末で録った録音の音声が再生できません

音声ファイルは録音した端末に保存され、他の端末には同期されません（ノートと文字起こしは同期されます）。一覧の「録音時間: … · 端末名」や、詳細画面の「録音元:」で、どの端末に音声があるか確認できます。
